# Изменения v0.3.1

- Удалён устаревший пакет `Microsoft.Windows.SDK.Contracts` — для `net8.0-windows10.0.19041.0` он не нужен и вызывал конфликты проекций WinRT.
- Надёжная регистрация горячих клавиш: `EnsureHandle()` + подписка на `SourceInitialized`.
- Улучшена обработка ошибок доступа к GSMTC (UnauthorizedAccessException).
- Более устойчивый выбор сеанса Яндекс Музыки.

# Изменения v0.3

- Исправлена история: отдельная строка на каждый сеанс прослушивания, отдельные вкладки «Хронология» и «Топ треков».
- Длительность записывается по ID конкретного сеанса, а не обновляет последнюю запись по совпадению названия.
- Выбор медиасеанса ограничен Яндекс Музыкой; браузеры и сторонние плееры не получают команды вместо неё.
- Улучшена регистрация глобальных горячих клавиш: сохраняются только реально зарегистрированные ID, ошибки показываются по каждой комбинации.
- Добавлена защита от второго экземпляра программы.
- Добавлено управление из контекстного меню системного трея.
- Добавлен переключатель автозапуска Windows для текущего пользователя.
- `start.bat` выполняет автономную публикацию при первом запуске; последующие запуски идут через готовый EXE.
- Исправлены кодировки BAT/VBS (UTF-8 без BOM).
- Добавлены статические smoke-тесты и Windows GitHub Actions workflow.
