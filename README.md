# Yandex Music Controller

Фоновый Windows-пульт для десктопной Яндекс Музыки. Программа использует системные медиасеансы Windows (GSMTC), глобальные сочетания клавиш, значок в системном трее и локальную SQLite-базу.

## Быстрый запуск

1. Windows 10 2004 (сборка 19041) или Windows 11, x64.
2. Для первого запуска из исходников установите **.NET 8 SDK**: https://dotnet.microsoft.com/download/dotnet/8.0
3. Дважды щёлкните `start-hidden.vbs` (запуск без окна консоли) или `start.bat` (видна диагностика сборки).
4. При первом запуске `start.bat` соберёт автономный EXE в `publish\`. В дальнейшем запускается уже он — SDK для работы программы не нужен.

Для ручной сборки запустите PowerShell и выполните `.uild.ps1`.

## Управление

- `Ctrl + Alt + ←` — предыдущий трек
- `Ctrl + Alt + →` — следующий трек
- `Ctrl + Alt + Пробел` — воспроизведение / пауза
- Закрытие главного окна скрывает программу в трей. Для завершения используйте меню значка в трее → «Выход».
- В меню трея доступны команды управления и история.
- Флажок «Запускать вместе с Windows» включает/выключает автозапуск текущего EXE для текущего пользователя.

## История

Вкладка «Хронология» показывает отдельные сеансы прослушивания по времени начала, треку, исполнителю и накопленной длительности. «Топ треков» агрегирует количество запусков и общее время. База: `%LOCALAPPDATA%\YandexMusicController\history.db`. Существующая таблица `History` сохраняется; миграция не удаляет старые записи.

Длительность накапливается по интервалам опроса медиасеанса. Погрешность обычно около интервала опроса; после долгой паузы или пропуска опроса один интервал ограничивается 10 секундами, чтобы не приписывать треку время сна/зависания компьютера.

## Совместимость Яндекс Музыки

Приложение не использует закрытые API и не читает внутренние файлы Яндекс Музыки. Оно управляет сеансом, который сама программа публикует в Windows GSMTC. При выборе сеанса ищется источник с `Yandex` в идентификаторе приложения. Другие плееры и браузеры намеренно не выбираются, чтобы команды не уходили не туда. Если конкретная сборка Яндекс Музыки не публикует GSMTC-сеанс или её идентификатор не содержит `Yandex`, получение названия трека и команды управления через этот механизм невозможны; это будет отображено в статусе. В таком случае потребуется отдельный проверенный интерфейс интеграции, которого в текущем проекте нет.

## Диагностика

- Если горячая клавиша занята другой программой, статус покажет, что зарегистрированы не все комбинации.
- Если трек не определяется, запустите Яндекс Музыку и начните воспроизведение; проверьте статус источника медиасеанса.
- Для подробной диагностики сборки запускайте `start.bat`, а не скрытый VBS.
- База и история хранятся только локально.

## Сборка

```powershell
dotnet restore
dotnet publish .\YandexMusicController.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

Технологии: C# 12, .NET 8, WPF, Windows GSMTC, WinForms NotifyIcon, Microsoft.Data.Sqlite.
